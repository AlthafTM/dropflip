# Dropflip design

User direction: invisible while idle; configurable drop area, default bottom left; white edge light with a soft halo when a file approaches the target; smooth expansion into a clean, small panel. Use dark graphite, white and gray like Dictately, with simple copy, good UX and Rust performance as priorities. This supersedes the initial visible shelf and broad gradient treatment.

ENERGY 1 / RHYTHM 2 / MOTION 2.

App identity: Dropflip. The desktop icon follows Dictately's reflected black-glass tile and monochrome rim, with two circular conversion arrows in place of its waveform. Solid triangular arrowheads give each thick curved shaft a clear direction at small sizes. The tray uses only the white arrows for small-size legibility. The EXE, window and shortcuts share this identity.

- The current direction is a cleaner dark utility with an actual light glow rather than a gradient wash. The body remains 97% opaque, with a nearly flat graphite fill and a quieter rim. A thin white source at the corner edges has two Gaussian bloom layers that now reach farther inward. The 420 × 330 footprint along the edges stays unchanged. Custom positions anchor the same light treatment to the chosen area.
- Segoe UI Semibold gives headings, filenames, format choices and primary actions a softer weight than the earlier bold display font. Segoe UI Regular lightens supporting text. Both are loaded from Windows with fallback fonts; no font files are downloaded or redistributed.
- White is the action/progress accent. Supporting surfaces use neutral gray, with no colored decorations.
- The main panel stays 320 × 286 points for every output format. File-type tiles and preview thumbnails are removed: the filename and metadata use the full header width beside the two action buttons. Long filenames pause for two seconds, scroll, pause for two seconds and reverse; short names remain still. The 112-point picker uses text with 16-point side insets and faded neighbours. Quality belongs inside the selected format card as a wider horizontal track and percentage. Unsupported formats have no track, but card/panel geometry stays fixed. Scroll, drag, click and keyboard navigation remain available. Convert and Change folder share a bottom-anchored footer. The folder action says only Change folder; its tooltip shows the saved destination. Downloads remains the initial default.
- Settings is 320 × 432 points with equal side/footer insets, matching corner/Move area controls, labeled size tracks, pill switches and an anchored Done action. Area selection and plus/minus controls manage independent spots, up to 1600 × 1000 points, bounded by the display. The placement guide is the actual drop rectangle with a centered Set here action. Settings opened through the file menu retains that file; the down arrow or Done returns to conversion. Direct/tray Settings uses X to close. Formats availability copy is removed.
- Native windows stay above ordinary and maximized apps without taking foreground focus at startup. A foreground fullscreen app on the primary display suppresses painting and drop interception and lowers the window. Show above fullscreen overrides suppression for idle areas; off by default. This corrects the earlier normal-stacking rule, which hid the target behind windowed apps. One transparent window tracks the nearest configured spot during a drag, avoiding one window/render loop per spot.
- Buttons use a small hover expansion and white bloom; text actions brighten without frames. Keyboard focus uses light on the control or slider thumb instead of square outlines. The options menu uses a rounded opaque graphite surface. Content fades, scales and follows the shell during view changes; reduced motion removes these movements. These small animations indicate interaction and opening, rather than adding idle decoration.
- A 360 ms opening anchors to the chosen corner, with roughly 5% overshoot, shell fade, delayed content fade and stable content layout. View changes also pop. The native canvas reserves the overshoot and resizes at transition boundaries rather than every animation frame. Closing briefly expands, then retreats over 300 ms. The proximity cue reaches farther and spreads up to 420 × 330 points along the screen edges. Only transitions, proximity glow and in-progress work animate. The idle window does not redraw continuously. Reduced motion disables movement.
- Each compressible format owns a quality slider inside its card. New files start at 100%; adjusting one format does not change another format's value, and returning restores the earlier setting for that file. Arrow keys, Home and End work while the track is focused. Percentages are quality choices, not exact file-size targets. The former separate Quality row and its height animation were removed to keep the interface stable.
- Successful completion stays visible for 2.5 seconds, then its text and shell fade and retreat over 300 ms. Queued files advance after this retreat. Errors remain visible until dismissed.
- No input/output type icons or image/video previews are rendered or generated. Removing that pipeline avoids full-resolution image decoding, thumbnail textures, PDF preview parsing and preview FFmpeg processes during a drop. The application/tray icon remains, with a thicker circular-arrow stroke and longer swept chevrons. It is generated from vector geometry by the existing asset script.
- Tab/Enter controls, Ctrl+O, Escape and native file/folder pickers provide alternatives to dragging. Fixed panels remain within the primary display's work area.
